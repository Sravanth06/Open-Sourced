## 👋 What is this?

Thanks to WebAssembly and a wave of AI-assisted reverse-engineering tools, it's now possible to take a big commercial game or a full software suite and get it running in a browser tab. Some of these projects are legitimate. Many are unauthorized copies of someone else's work, hosted out in the open.

**Open-Sourced** keeps a public, organized directory of where those copies show up, so the people who own the work can find them quickly.

## 🎯 Why does it exist?

Finding unauthorized clones is slow, scattered work, and no single studio or legal team can watch the whole internet. By pooling what the community spots, this project helps copyright holders, original developers, and publishers to:

1. **Spot** unauthorized distribution of their work.
2. **Trace** who is hosting it (Cloudflare, Vercel, AWS, and so on).
3. **Act** with fast, targeted DMCA takedown notices.

> [!IMPORTANT]
> This repository **does not** host, promote, or encourage piracy. There is no source code, no game assets, and no reverse-engineering tutorials here. It is a reporting tool for rightsholders.

## 📂 How the repo is organized

Everything is sorted by type, then by title. Each title has its own folder with a dedicated `README.md` holding all the tracked details for that title.

```text
Open-Sourced/
├── README.md                  ← you are here
├── Games/
│   ├── GTA-V/
│   │   └── README.md          tracked entries for GTA V ports
│   └── RDR2/
│       └── README.md          tracked entries for Red Dead Redemption 2 ports
└── Software/
    ├── Adobe-Photoshop/
    │   └── README.md          tracked entries for Photoshop web clones
    └── Adobe-Premiere/
        └── README.md          tracked entries for Premiere web clones
```

## 🤝 Contributing

Each title's README explains exactly what an entry needs and how to format it. A few rules apply everywhere:

- ✅ **Verify before you submit.** Make sure it really is a copy of the named title.
- ❌ **No files, assets, source code, or "how it was done" write-ups.** PRs containing them will be closed.
- ❌ **No accusations about people.** We list URLs, not names.
- ⚠️ **Accuracy matters.** Fan projects, licensed ports, and original games that merely resemble a big title are not unauthorized clones.

Listed by mistake? Open an issue and we'll review it promptly.
